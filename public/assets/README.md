# Carpeta de assets visuales — NEXUS FF

Colocá acá tus imágenes propias. El código las buscará en esta carpeta.

## Archivos esperados

| Archivo                        | Dónde se usa                                      | Tamaño recomendado |
|-------------------------------|---------------------------------------------------|-------------------|
| `logo.png`                    | Header, favicon fallback, emails                 | 200×200 px        |
| `logo-blanco.png`             | Header sobre fondo oscuro                        | 200×200 px        |
| `banner-hero.jpg`             | Fondo del hero en la landing                     | 1920×1080 px      |
| `og-default.jpg`              | Imagen Open Graph por defecto (links en redes)   | 1200×630 px       |
| `og-torneo.jpg`               | Imagen OG base para páginas de torneos           | 1200×630 px       |
| `auth-bg.jpg`                 | Fondo en páginas de login/registro               | 1200×1600 px      |
| `favicon.ico`                 | Reemplaza el icono del navegador                 | 32×32 px          |

## Formatos aceptados
PNG, JPG, WEBP. Máx 2MB por imagen.

## Cómo activar cada imagen
Una vez que pongas los archivos acá, avisale a la IA qué archivos colocaste
y te va a integrar cada una en el lugar que corresponde del código.
